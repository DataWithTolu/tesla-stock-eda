# Tesla Stock Price Analysis

### Exploratory Data Analysis of Tesla Historical Stock Performance

## Project Overview

This project analyzes Tesla historical stock price data using Python to identify trends in price performance, daily returns, volatility, trading volume, and intraday price movements.

The project demonstrates an end-to-end exploratory data analysis workflow, from data preparation and quality checks to statistical analysis and visualization.

## Objectives

- Analyze Tesla's historical closing price trend
- Evaluate daily stock returns
- Examine historical volatility
- Analyze trading volume
- Compare yearly and monthly performance
- Investigate the relationship between trading volume and price movements

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Key Findings

- Average daily return: approximately **0.21%**
- Daily return standard deviation: approximately **3.63%**
- Average daily trading volume: approximately **96.58 million shares**
- Volume vs. daily return correlation: **0.08**
- Volume vs. intraday price range correlation: **0.50**
- 2020 recorded the highest average daily return among the years analyzed
- 2022 recorded the lowest average daily return among the years analyzed

## Key Insight

Trading volume showed only a very weak relationship with daily returns but a moderate positive relationship with intraday price range.

This suggests that higher-volume trading days tended to experience larger within-day price movements. However, correlation does not establish causation.

## Analysis Areas

The notebook explores:

1. Tesla closing price trends
2. Yearly average closing prices
3. Daily returns
4. Rolling volatility
5. Trading volume
6. Yearly performance
7. Monthly performance
8. Trading volume and intraday price movement

## Limitations

This project is descriptive rather than predictive. Historical relationships do not guarantee future stock performance, and the analysis does not account for every factor that can influence stock prices.

This analysis should not be interpreted as investment advice.
